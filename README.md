Приложение для анализа транзакций
Это приложение предназначено для анализа транзакций, хранящихся в Excel-файлах. Оно предоставляет функциональность генерации JSON-данных для веб-страниц, формирования Excel-отчетов и реализации различных сервисов.

Выбранные задачи по категориям
Веб-страницы
Главная: Отображение основной страницы приложения с общим доступом к данным и функционалу.
Сервисы
Простой поиск: Возможность поиска транзакций по ключевым словам в различных полях данных.
Отчеты
Траты по категориям: Генерация отчетов, показывающих расходы, сгруппированные по категориям.
Тестирование
Для всех реализованных функций написаны модульные тесты, которые обеспечивают проверку корректности работы приложения. Тесты покрывают основные сценарии использования, включая обработку ошибок и валидацию данных.
